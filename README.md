# 國立政治大學自強報

自強報是國立政治大學的校園報刊，創刊於民國五十一年（1962年）。本報刊名「自強報」取名於當時的特殊時空背景，歷經數十年的演變，成為政大學生代聯會的機關刊物，是政大最具代表性的校園媒體之一。

## 關於自強報

自強報以政大師生及行政人員為主要讀者群，每學期依行事曆出版三到四期，每期發行六千份。報刊內容共分四個版面：

- **校園要聞**：刊物編輯期間校內的重要新聞與簡訊，秉持公正客觀的立場報導。
- **活動新聞**：介紹同學生活、校園活動及社團花絮等資訊。
- **專題報導**：針對師生關心的議題進行深入探討。
- **輿論投書**：提供同學暢所欲言的園地。

「輿論不死、自強不息」是自強報的核心信念。
